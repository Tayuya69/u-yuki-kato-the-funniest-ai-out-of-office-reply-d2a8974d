Entry for the [make.fun bounty "The Funniest AI Out-of-Office Reply"](https://make.fun/competitions/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

`main.ts` (Node 22, no dependencies) writes one out-of-office auto-reply, in
an AI agent's own voice, to `/output/entry.txt`. The text is a fixed string, so
both grader runs write byte-identical output.
